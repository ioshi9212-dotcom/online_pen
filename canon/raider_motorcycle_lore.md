# Мотоциклы рейдеров

Мотоциклы рейдеров — не обычные старые байки.

Это транспорт для эвакуации, рейдов, вирусных/эхо-ситуаций и спасения.

## Норма оснащения

- рассчитаны максимум на трёх человек в экстренной ситуации;
- могут перевозить раненого;
- у каждого рейдера аптечка;
- есть инструменты;
- есть аварийный набор;
- есть средства фиксации/перевязки.

## Командиры

У командиров может быть личное оружие. У Райдена допустимо обычное служебное оружие/пистолет.
