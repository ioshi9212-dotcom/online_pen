# Admin services redesign patch

Что изменено в разделе `/admin/services`:

- добавление услуги теперь открывается отдельным модальным окном `?add=1`;
- редактирование услуги теперь открывается отдельным модальным окном `?edit=<id>`;
- список услуг стал компактным: название, статус, описание, цена, длительность, действия;
- добавлена защита от дублей по названию услуги без учета регистра;
- после действий появляются всплывающие сообщения: добавлено, сохранено, скрыто, показано, удалено, дубль;
- добавлены кнопки скрыть/показать услугу;
- добавлено удаление услуги, если по ней нет записей;
- если по услуге уже есть записи, удаление не ломает историю — услуга просто скрывается;
- скрытые услуги вынесены в отдельный раскрывающийся блок;
- стрелки перемещения остались, но больше не занимают половину страницы.

Файлы:

- `app/admin/services/page.tsx`
- `app/admin/services/actions.ts`
- `app/globals.css`
