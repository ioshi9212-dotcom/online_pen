# Структура интерфейса

## Публичные страницы

| Страница | Роль | Главные действия |
|---|---|---|
| `/` | Главная | Записаться / Я уже клиент / Прайс |
| `/price` | Прайс | Записаться / Я уже клиент |
| `/register` | Заявка нового клиента | Отправить заявку |
| `/login` | Вход клиента | Войти |
| `/pending` | Ожидание подтверждения | На главную / Прайс |
| `/unavailable` | Нет доступа | Попробовать вход / На главную |

## Клиентские страницы

| Страница | Роль | Главные действия |
|---|---|---|
| `/my?client=token` | Личный кабинет | Новая запись / Прайс / Лист ожидания / Отменить запись |
| `/booking?client=token` | Запись | Услуга → окно → время → отправка заявки |

## Админка

Публичная навигация больше не показывает админку. Открывать напрямую: `/admin`.

Клиенты видят только окна из `OnlineWindow`. Управление ими остаётся в `/admin/schedule` и `/admin/schedule/free`.
