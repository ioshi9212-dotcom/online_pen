# Online Pen — закрытая онлайн-запись мастера

Мини-сайт для записи клиентов: регистрация, подтверждение мастером, скрытое расписание, заявки на запись, админка, прайс и чёрный список.

## Что уже заложено

- Next.js App Router + TypeScript
- PostgreSQL через Prisma
- деплой на Railway
- клиентская регистрация без email
- вход клиента по телефону + дате рождения
- клиент видит расписание только после подтверждения
- заявка на запись получает статус `PENDING` и сразу занимает слот
- админ подтверждает/отклоняет заявки
- бан клиента без грубого текста на клиентской стороне
- редактируемые услуги/прайс
- расписание по дням недели
- закрытие отдельных окон времени
- базовая админ-авторизация через пароль

## Локальный запуск

```bash
npm install
cp .env.example .env
npm run db:push
npm run seed
npm run dev
```

Открыть:

- клиентская часть: http://localhost:3000
- админка: http://localhost:3000/admin

## Переменные Railway

В Railway нужно добавить PostgreSQL и переменные:

```env
DATABASE_URL="${{Postgres.DATABASE_URL}}"
ADMIN_PASSWORD="поставь_свой_пароль"
ADMIN_SECRET="любой_длинный_секрет"
NEXT_PUBLIC_APP_NAME="Online Pen"
NEXT_PUBLIC_MASTER_WHATSAPP="79999999999"
APP_TIMEZONE="Asia/Vladivostok"
```

## Логика статусов

### Клиенты

- `PENDING` — заявка на регистрацию отправлена, расписание скрыто.
- `APPROVED` — клиент подтверждён, расписание открыто.
- `REJECTED` — заявка отклонена.
- `BANNED` — клиент заблокирован, расписание скрыто.

### Записи

- `PENDING` — клиент занял окно, ждёт подтверждения мастера.
- `CONFIRMED` — мастер подтвердил запись.
- `CANCELLED_BY_CLIENT` — клиент отменил запись.
- `CANCELLED_BY_ADMIN` — мастер отменил запись.
- `REJECTED` — мастер отказал в записи.
- `COMPLETED` — клиент пришёл.
- `NO_SHOW` — клиент не пришёл.

## Важный принцип

Слот считается занятым, если запись имеет статус:

- `PENDING`
- `CONFIRMED`

То есть пока мастер не подтвердил заявку, это время уже не показывается другим клиентам.

## Railway

Проект готов к Railway. В `railway.json` указано:

- build: `npm install && npm run build`
- start: `npm run db:push && npm run start`

Это удобно на старте: Railway сам применит структуру Prisma к базе.
