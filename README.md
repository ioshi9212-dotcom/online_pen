# Онлайн-запись мастера

Мини-приложение для одного мастера маникюра: регистрация клиентов, подтверждение доступа, прайс, онлайн-окна, ручная запись и кабинет мастера.

## Главное

- Клиент сначала отправляет заявку.
- Мастер подтверждает клиента в админке.
- Подтверждённый клиент видит личный кабинет, прайс, свои записи и доступные онлайн-окна.
- Мастер управляет расписанием, онлайн-окнами, заявками, клиентами и прайсом.

## Команды

```bash
npm install
npm run prisma:generate
npm run db:push
npm run seed
npm run dev
```

## Переменные окружения

Скопируйте `.env.example` в `.env` и заполните реальные значения:

```bash
cp .env.example .env
```

Обязательные переменные:

- `DATABASE_URL` — подключение к PostgreSQL.
- `ADMIN_PASSWORD` — пароль входа в кабинет мастера.
- `ADMIN_SECRET` — длинная случайная строка для cookie.
- `APP_TIMEZONE` — рабочий часовой пояс. Сейчас используется `Asia/Vladivostok`.

## Основные страницы

### Клиент

- `/` — стартовая страница.
- `/register` — заявка на доступ.
- `/login` — вход клиента по телефону и дате рождения.
- `/my` — личный кабинет клиента после безопасного входа.
- `/profile` — профиль клиента.
- `/price` — прайс.
- `/preview` — интерактивное превью нового клиентского пути без отправки данных.

### Мастер

- `/admin` — главное меню мастера: сегодня, завтра, быстрые действия.
- `/admin/schedule` — раздел расписания.
- `/admin/schedule?view=mode` — настройки записи.
- `/admin/schedule?view=calendar` — календарь окон.
- `/admin/schedule/free` — список открытых онлайн-окон.
- `/admin/manage` — ручная запись.
- `/admin/my-clients` — база клиентов.
- `/admin/services` — прайс и услуги.
- `/admin/profile` — профиль мастера и пароль админки.

## Клиентская сессия

После входа клиент определяется по подписанной HttpOnly-cookie. Постоянный токен клиента не передаётся в URL, формах или JSON-запросах.
