Патч: мобильная главная мастера + проверка кнопок + подтверждение отмены клиентом.

Файлы:
- app/admin/page.tsx
- app/admin/actions.ts
- app/admin-master-mobile.css
- app/layout.tsx
- lib/cancellationNotice.ts
- package.json
- scripts/button-audit.mjs

Что меняется:
1. Мобильная главная мастера:
   - сверху текст "Главная" и дата;
   - справа рабочая кнопка "Новая запись" -> /admin/manage;
   - блоки "Сегодня" и "Завтра" с количеством записей;
   - строки записей: время, длительность, клиент, услуга, статус, стрелка для перехода в расписание;
   - блоки "Заявки на запись" и "Регистрация";
   - блок "Ждуны" с кнопкой "Записать";
   - нижнее фиксированное меню: Главная, Календарь, Клиенты, Настройки, Клиент.

2. Отмена клиентом:
   - отменённая клиентом запись показывается в Сегодня/Завтра как "Клиент отменил";
   - рядом есть кнопка "Видела";
   - после нажатия запись скрывается с главной мастера;
   - окно остаётся свободным, потому что статус CANCELLED_BY_CLIENT не блокирует новую запись.

3. Проверка кнопок:
   - добавлен скрипт npm run test:buttons;
   - он ищет пустые <button>/<a> без текста, aria-label или title;
   - проверяет явные статические ссылки на несуществующие страницы/route.

Как ставить:
1. Распаковать zip.
2. Скопировать файлы в корень проекта online_pen с заменой.
3. Запустить:
   npm run test:buttons
4. Потом обычный build/deploy.

Важно:
Схема базы НЕ меняется. Для отметки "Видела" используется adminComment со служебной меткой.
