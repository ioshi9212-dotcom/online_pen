# Что изменено в этой сборке

Сборка переделана под логику “закрытая запись к мастеру” без салонного/домашнего вайба.

## Главный клиентский маршрут

1. `/` — главный экран: понятные кнопки `Записаться`, `Я уже клиент`, `Прайс`.
2. `/register` — новый клиент отправляет заявку.
3. `/pending` — ожидание подтверждения доступа.
4. `/login` — вход постоянного клиента по телефону и дате рождения.
5. `/my?client=...` — центр клиента: активные записи, новая запись, прайс, лист ожидания.
6. `/booking?client=...` — запись по шагам: услуга → ближайшие окна → время → подтверждение заявки.

## Важная логика записи

Клиент теперь видит только `OnlineWindow`, то есть только те окна, которые мастер вручную открыл в админке. Общие свободные слоты из расписания больше не показываются клиенту сами по себе.

Это исправляет старую проблему: клиент видел время, нажимал его, а сервер потом отвечал, что окно не открыто онлайн.

## Кнопки

- `Записаться` на главной ведёт в `/register`.
- `Я уже клиент` ведёт в `/login`.
- После успешного входа клиент попадает в `/my`, а не сразу в `/booking`.
- В личном кабинете основная кнопка `Новая запись` ведёт в `/booking?client=...`.
- В записи клик по времени больше не создаёт заявку сразу. Сначала открывается панель проверки, потом кнопка `Отправить заявку`.

## Тексты и уведомления

Добавлены более живые, сухие сообщения без прямого вайба “дом/салон”:

- `Заявка отправлена. Я подтвержу — и место будет железно.`
- `Это окно уже уехало. Выберите другое.`
- `Запись отменена. Спасибо, что не исчезла в туман.`
- `Дата не совпала. Проверь цифры — сайт не экстрасенс.`

## Дизайн

CSS полностью обновлён: тёмный фон, розовый акцент, карточки, понятная иерархия, меньше “девчачьего 2000-го”.

Админка не вынесена в публичное меню. Открывается прямым переходом на `/admin`.
